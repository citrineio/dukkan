# Future concept: Library shelves

Status: idea for a future Dukkan revision. Do not include in the current Sprint 2 feedback update.

The Library section should feel like a physical game library, with game boxes arranged on shelves. Moving Up and Down with the D-pad should move between shelves. The highlighted game should look as though its box has been pulled forward from its shelf, while the other boxes remain upright in place.

Kadhem plans to provide a reference image later. Use that image to settle the visual treatment and spacing before implementation. The exact left/right behavior, animation, accessibility cues, and layout at different game counts remain open design decisions.
